STONE AWARDS 2026 — обновление интерфейса и голосования

Что изменено:
- Новый каменно-серый дизайн с морскими зелёно-бирюзовыми стеклянными акцентами.
- На главной странице сначала отображаются все открытые номинации.
- Нажатие на карточку открывает отдельную страницу с кандидатами именно этой номинации.
- В разделе голосования также можно открыть любую доступную номинацию.
- Объявленные, но закрытые номинации вынесены в отдельный нижний блок.
- Список открытых номинаций автоматически обновляется каждые 15 секунд и при возвращении на вкладку.
- Открытие секретной номинации для голосования автоматически публикует её для участников.
- Исправлена серверная логика выдачи секретных открытых номинаций и проверки права голоса.

Важно:
- Демо-режим по-прежнему хранит данные только в localStorage текущего браузера.
- Если Supabase уже подключён, выполните обновлённый файл supabase/schema.sql в Supabase → SQL Editor.
  Скрипт обновляет функции через CREATE OR REPLACE и не удаляет существующие голоса.
- После этого опубликуйте обновлённые файлы сайта на вашем хостинге.


НОВЫЙ СПИСОК НОМИНАЦИЙ И НОМИНАНТОВ
- В демо-режиме заменён стартовый список на 20 номинаций и 13 указанных участников.
- Старые демо-данные не подхватываются: используется новый ключ localStorage v2.
- Все 13 номинантов добавлены во все обычные номинации.
- «Пидорас года» зафиксирована за КАБАНОМ и не участвует в голосовании.
- Добавлен supabase/seed_nominees.sql для замены старых категорий в уже подключённом Supabase.
- ВНИМАНИЕ: запуск seed_nominees.sql удаляет старые категории, связанные голоса и записи номинантов. Учётные записи существующих участников сохраняются. Для отсутствующих кандидатов скрипт создаёт учётные записи и в конце выводит их новые коды доступа.
- «Дуо года» пока использует общий список отдельных участников; для голосования именно за пары нужно отдельно прислать состав пар.


НОВОЕ: СМЕНА КОДА У СУЩЕСТВУЮЩЕГО УЧАСТНИКА
- В панели организатора у каждого участника появилась кнопка «Сменить код доступа».
- Новый код показывается один раз; его можно скопировать и отправить участнику.
- Старый код и активная сессия аннулируются.
- ID участника не меняется, поэтому все ранее записанные голоса и номинации сохраняются.
- Для Supabase повторно выполните обновлённый schema.sql в SQL Editor (он добавляет безопасную RPC-функцию; таблицы и голоса не удаляются).
